# 标注要求与出图规范

本文件是标注与出图的通用细则。各专项的特殊标注内容见 `assets/visualization_kb.json` 中每个专项的 `annotation` 字段。

---

## 一、标注要求

### 1.1 标注的三个层级

专项可视化图面上的信息应分三层，不能混在一起：

| 层级 | 内容 | 载体 |
| --- | --- | --- |
| 分类层 | 分区/等级/系统名称 | 颜色 + 图例，**不逐个构件标注** |
| 定量层 | 数值、规格、限值对照 | 引线标注、表格 |
| 校核层 | 是否满足要求 | 结论标注（如「28m ≤ 30m 满足」），不满足处用警示色 |

最常见的错误是把分类层的信息写进定量层 —— 例如在疏散图上给每一个房间都标一遍「疏散路径」，而真正需要标注的疏散距离反而没标。

### 1.2 引线与文字

- 引线**正交引出**，斜引线仅用于特殊节点
- 引线不得穿越其他构件，不得相互交叉；交叉无法避免时应调整标注位置而非强行拉线
- 同一张图内标注字高统一（常规 2.5~3.5mm），不得出现多种字号
- 三维视图的标注必须带引线指向构件表面，不能浮在空中 —— 浮空标注在视角旋转后会指向错误构件

### 1.3 定量标注的必填项

任何数值型标注都应满足「值 + 单位 + 对照/依据」三要素：

| 专项类型 | 必填内容 | 示例 |
| --- | --- | --- |
| 指标校核类 | 实测值 + 单位 + 规范限值 + 结论 | `疏散距离 28m ≤ 30m 满足` |
| 构件参数类 | 规格 + 间距 + 特殊参数 | `φ25×3000 @1200×1200 倾角15°` |
| 云图类 | 色阶刻度 + 单位 + 工况 | `最大位移 12.4mm（工况：D+L）` |
| 分区类 | 分区名称 + 边界 + 面积 | `防火分区 F-3 面积 1420㎡ ≤ 1500㎡` |

### 1.4 分区类专项的标注原则

分区类（辐射防护分区、防火分区、功能分区、施工分区）的标注对象是**分区边界与分区名称**，不是构件：

1. 分区边界用粗线（≥0.5mm）明示，形成闭合轮廓
2. 在分区几何中心标注分区名称与编号，字号可以大于其他标注
3. 分区面积与规范限值的对照放在图例或说明表格中，不写在分区内部（会与房间名称冲突）
4. 分区边界上的**开口必须逐一标注处理方式** —— 这是分区类专项最容易被忽略、也最被审图关注的内容

### 1.5 云图类专项的标注原则

云图类（应力分布、日照分析、能耗分析、监测预警）**原则上不标注单个构件**：

1. 用色阶条 + 刻度代替构件标注
2. 只标注极值点及其数值
3. 必须标注工况/日期/时间带等前提条件 —— 脱离前提的云图结论不成立
4. 变形类云图必须标注放大倍数

## 二、出图规范

### 2.1 图纸比例

| 图纸类型 | 常用比例 | 说明 |
| --- | --- | --- |
| 总平面 / 场地分析 | 1:500、1:1000 | 与总图专业保持一致 |
| 平面图 | 1:100、1:200 | 建筑类常规 1:100，场地类 1:200 |
| 剖面图 | 1:50、1:100 | 结构类偏 1:50，机电类偏 1:100 |
| 节点大样 | 1:10、1:20、1:50 | 按节点复杂程度选择 |
| 系统轴测图 | 1:200、1:500 | 以图面可读为准，不强求标准比例 |
| 云图 / 分析图 | 不限比例 | 但须标注视图方向与坐标 |

**同一套图纸的比例应尽量统一**，尤其是需要横向对比的图（如多方案比选、多层楼分布）。比例不一致的图放在一起对比，结论会被误导。

### 2.2 图幅与标题栏

按 GB/T 50001《房屋建筑制图统一标准》：

- 常规图幅：A0（1189×841）、A1（841×594）、A2（594×420）、A3（420×297）
- 专项分析图建议 A1 或 A2，A0 太大不便于会议传阅，A3 太小看不清标注
- 标题栏必须包含：工程名称、图名、图号、比例、设计单位、日期、专业会签栏
- 图号编制规则应在项目级统一，例如 `XX-可视化-疏散-001`

**长图幅的建议**：线性工程（管廊、隧道、管线）的展开图往往需要加长图幅，应按标准加长幅面（如 A1 加长至 1189×841 的 2~3 倍）并注明，不要用非标准比例拉伸。

### 2.3 线宽与填充

| 要素 | 线宽 |
| --- | --- |
| 主要构件轮廓 | 0.35~0.5mm |
| 次要构件轮廓 | 0.25mm |
| 分区边界（强调） | ≥0.5mm |
| 标注、图例、索引 | 0.15~0.18mm |

填充图案的原则：**颜色 + 花纹双重编码**。纯色填充在黑白打印时会全部变成灰，无法区分。建议：

- 重点/危险区：斜线或交叉线填充
- 次重点区：点状填充
- 一般区：纯色填充

### 2.4 颜色输出

- 图纸打印优先使用**填充图案**传递信息，颜色作为辅助
- PDF 输出前统一色彩配置（RGB 或 CMYK），避免不同电脑输出的颜色不一致
- 彩色出图时检查：同一色系内相邻档次的色差是否足够；相邻但不相关的分区是否误用了相近色

### 2.5 图纸配套

专项可视化图不能孤立出图，必须与相关图纸成套，否则无法支撑结论：

| 专项 | 必须配套的图纸/文件 |
| --- | --- |
| 辐射防护分区 | 通风系统图、安全标识布置图、环评批复文件 |
| 管线综合 | 碰撞检测报告、净高分析图、综合支吊架图 |
| 支护结构 | 地质纵断面图、监测布点图、施工工序图 |
| 疏散路线 | 防火分区图、消防设施图、总平面消防图 |
| 防火分区 | 疏散图、消防设施图、面积计算表 |
| 地质分层 | 岩土工程勘察报告、基础设计图 |
| 应力分布 | 计算书、荷载工况汇总表 |
| 监测点 | 监测方案、支护设计图 |

### 2.6 图纸说明

每套专项图应附一段图纸说明，至少包含：

1. 专项分析的目的与依据规范（列出规范编号与条文号）
2. 数据来源（模型版本、计算软件与版本、勘察报告编号等）
3. 关键结论的定量表述（如「全楼共 126 间房间，疏散距离均满足 GB 50016 第 5.5.17 条要求」）
4. 遗留问题与待确认事项

图纸说明是审图与汇报时最常被追问的部分，事前写清楚可以省掉大量往返。
