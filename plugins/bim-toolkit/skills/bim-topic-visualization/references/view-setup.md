# 视图设置操作细则（Revit / Navisworks）

本文件是各专项视图设置的操作手册。`assets/visualization_kb.json` 里每个专项只给要点，具体点击路径在这里。

---

## 一、总原则

无论用什么软件，专项视图都遵循同一条链路：

```
建立独立视图样板 → 确定可见性范围 → 建立分类/过滤器规则 → 逐类赋色 → 定型视角 → 保存视图并命名
```

**顺序不能颠倒**。先调视角再改配色，会导致已定的视点被后续的可见性变化破坏；多个视图各自调色而不共用样板，则必然出现「同物异色」。

一条铁律：**同一专项的配色规则只能定义一次**。在 Revit 里定义为过滤器，在 Navisworks 里定义为 Search Set + Appearance Profiler 规则，而不是在每张图上手工涂色。

## 二、Revit

### 2.1 建立视图样板（必须先做）

1. `视图` 选项卡 → `视图样板` → `管理视图样板`
2. 从 `无` 新建，命名为「可视化-<专项名>」，例如「可视化-疏散路线」
3. 勾选 `V/G 替换`、`详细程度`、`视图比例`、`可见性/图形替换` 三项
4. 之后所有该专项视图通过 `属性面板 → 视图样板 → <样板名>` 应用，改样板即全图同步生效

### 2.2 可见性/图形替换（VV / VG）

快捷键 `VV` 或 `VG` 打开「可见性/图形替换」对话框，三个页签各有用途：

| 页签 | 用途 | 专项场景 |
| --- | --- | --- |
| 模型类别 | 按构件类别整体开关与替换 | 关闭家俱、设备等无关类别 |
| 注释类别 | 标注、轴网、标高的显隐 | 只保留必要标注 |
| 导入的类别 | CAD 底图图层控制 | 控制底图显隐 |

对于专项可视化，建议在「模型类别」中把无关类别**取消勾选**而非设为透明 —— 透明构件在轴测图中仍会干扰视线，且渲染耗时显著增加。

### 2.3 过滤器（专项目录配色的核心）

`VV` → `过滤器` 页签 → `编辑/新建`

按专项需要创建过滤器，规则示例：

- **按系统分类**（管线综合）：`系统分类` 等于 `给水` / `排水` / `电力` …
- **按类型名称**（支护结构）：`类型名称` 包含 `锚杆` / `钢架` / `喷射混凝土` …
- **按共享参数**（辐射防护分区、防火分区、功能分区）：这一类没有现成的系统参数，**必须先建共享参数**，例如 `分区名称`，再在过滤器里按该参数取值过滤。这是分区类专项绕不开的前置工作。
- **按高度区间**（净高分析）：`底部高程` 大于 / 小于某值

过滤器建立后，在 `VV` 中为每个过滤器设置「投影/表面」的**填充图案 + 前景色 + 背景色**三件套：

- 填充图案：`实体填充` 用于色块表达；`斜线` / `点状` 用于黑白可辨的辅助表达
- 前景色：分区主色
- 背景色：一般设白色或与前景一致，否则会形成双色混合

**注意**：过滤器优先级由列表自上而下决定，重叠构件取最上面的规则。分区类专项应把「重点/异常」类过滤器放在最上方。

### 2.4 剖切框（Section Box）

1. 在三维视图中选中剖切框（`属性面板 → 范围 → 剖切框` 勾选后出现）
2. 用拖拽手柄调整范围，或在 `视图 → 剖切框` 中精确设定标高
3. 剖切框确定后**锁定**，避免误拖

分区类专项建议按人员活动高度（1.2m）与管道层（1.5m~2.2m）分别剖切，两张图对照看。

### 2.5 图形显示样式

| 样式 | 适用 | 说明 |
| --- | --- | --- |
| 隐藏线 | 疏散路线、防火分区等需要清晰线型的图 | 构件不填充，线条清晰，最省渲染时间 |
| 着色 | 分区体块、支护构件分色 | 显示表面颜色但无材质纹理，**专项可视化的默认选择** |
| 一致颜色 | 需要强调轮廓而非材质 | 全模型单色，靠过滤器着色 |
| 真实 | 汇报用的最终效果图 | 渲染慢，仅用于少量关键图 |

### 2.6 正交视图与透视

- 专项分析图**一律用正交（Parallel）投影**，不用透视。透视会让管线、构件的位置关系产生视觉误导，审批时容易引起争议。
- 设置方式：三维视图属性面板 → `相机` → `投影模式` → `正交`
- 汇报用效果图可用透视，但不得作为分析依据出图。

### 2.7 明细表辅助校核

可视化解决「看得见」，明细表解决「算得清」。建议对每个专项同步建一张明细表：

`视图 → 明细表 → 明细表/数量`，按专项分类字段分组统计，用于核对图面颜色与数据的对应关系。例如疏散专项按房间统计疏散距离，管线综合按系统统计长度。

## 三、Navisworks

Revit 适合「设计逻辑」，Navisworks 适合「整合与汇报」。多专业模型汇总后的专项表达，基本都在 Navisworks 里做。

### 3.1 选择集与搜索集（一切的基础）

- **选择集（Selection Sets）**：手工逐个选构件保存，适合小规模、精确控制
- **搜索集（Search Sets）**：用属性条件自动匹配，**专项可视化必须用搜索集**，因为模型更新后能自动重新匹配

创建路径：`常用 → 选择树 → 集合（Sets）` 窗口 → 右键 → `新建搜索集`

搜索集规则示例：

| 专项 | 搜索条件 |
| --- | --- |
| 管线综合 | `Item → Type` 包含 `Pipe`；或按 `Layer` / 自定义属性按系统分 |
| 支护结构 | `Item → Type` 包含 `Anchor` / `Steel Arch` / `Shotcrete` |
| 疏散路线 | `Item → Layer` 包含 `Wall` / `Door` / `Stair` |
| 辐射防护分区 | 按自定义属性 `Zone` 或 `Room Name` 匹配 |

**关键技巧**：搜索集的条件要写「包含」而不是「等于」。模型命名总会带前后缀，用等值匹配会在下一版模型失效。

### 3.2 Appearance Profiler（批量配色的正确做法）

这是 Navisworks 里做专项配色最该用的工具，很多人却手工一个个改颜色。

路径：`视图 → 窗口 → Appearance Profiler`

1. `Appearance Profiler` 面板 → 选择 `Datasource`（数据源）为 `Selection Sets` 或 `Sets Tree`
2. 添加规则行，每行绑定一个集合 + 一组颜色/透明度/线型设置
3. 点击 `Apply` 一键批量套用

优势：配色规则可保存为 `.dat` 文件（`Export Profile`），下一版模型直接 `Import Profile` 复用，保证多轮模型之间颜色完全一致。**这是保证「颜色统一」这一检查项最有效的手段。**

### 3.3 覆盖颜色与透明度

单个或少量构件临时调整：选中构件 → 右键 → `Override Item` → `Override Color` / `Override Transparency`。

透明度建议值：

| 对象 | 透明度 | 原因 |
| --- | --- | --- |
| 结构构件（梁板柱） | 0%（不透明） | 必须体现避让关系 |
| 分区体块 | 60%~75% | 能看到内部又不遮挡 |
| 需要透视查看的管线 | 50%~60% | 兼顾可读 |
| 无关背景构件 | 直接隐藏，不要设透明 | 透明仍参与渲染，拖慢速度 |

### 3.4 剖切（Section Plane / Section Box）

- 自由剖切面：`视图 → 剖切面` → 选择前/后/左/右/顶/底或自由面
- 剖切盒：`视图 → 剖切盒`，各面可独立启用
- 保存剖切位置：在 Viewpoint 中保存，不要每次重新拖

系列剖切（如隧道每 5~10m 一处）建议用 `Viewpoints` 逐个保存并命名，命名规则「<专项>-<里程/轴号>-<视图类型>」。

### 3.5 视点与动画

- **保存视点**：`Viewpoints` 面板 → `Add Viewpoint`（`Ctrl+Shift+V`），视点会记录视角、剖切、可见性与覆盖色
- **视点命名规则**：`<专项>_<位置>_<类型>`，例如 `疏散_3F_平面`、`管综_走道A_剖面`
- **动画**：`动画 → 动画播放`（简单漫游）或 `Timeliner`（按进度驱动，4D 模拟）
- 汇报用动画建议 1280×720 或 1920×1080、25fps，导出前先设好视点序列并统一视角高度

### 3.6 碰撞结果的可视化

Navisworks 的 Clash Detective 结果可以直接驱动可视化：

1. `Clash Detective` → 选择测试 → `结果` 页签
2. 右键 → `Switchback` 定位到模型，或用 `结果 → 导出` 生成 `.xml` / `.html`
3. 把碰撞点作为标记导入：`常用 → 标记 → 新建标记`，或用第三方插件批量导入碰撞点
4. 按严重等级分组配色（红/橙/黄），并在 `Sets` 中按等级建立集合

如果项目同时使用「BIM 碰撞检测报告整理」工具（`bim-clash-analysis` Skill）生成的 Excel 明细，可按碰撞编号建立标记，实现图-表一一对应。

### 3.7 渲染输出

`文件 → 导出 → 图像`，或 `渲染` 面板。专项分析图建议：
- 关闭抗锯齿以外的所有后期效果
- 背景设为纯白或纯灰，避免花哨背景干扰
- 分辨率不低于 1920×1080，图纸用图按 300dpi 输出

## 四、跨软件一致性

同一专项在 Revit 与 Navisworks 中出图时，必须保证颜色一致。做法：

1. 在 Revit 中定义过滤器配色时，**记录每个类别的 RGB 值**
2. 在 Navisworks 的 Appearance Profiler 中，手工输入相同的 RGB 值
3. 建议维护一份项目级的「专项配色对照表」（可用本 Skill 生成的 HTML 方案书作为该表），Revit 与 Navisworks 两侧都从这张表取值

如果两侧使用不同色值，汇报时同一构件在两张图上颜色不同，会直接影响方案的可信度。
