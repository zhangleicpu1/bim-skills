# PPT 页面设计与排版规范

答辩 PPT 的视觉不是审美问题，是**可读性问题**。评委坐在几米外的投影前，只扫几秒。这一份是排版的硬规则。

## 一、字号：按「最后一排能否看清」倒推

投影尺寸未知，所以按最保守的取值。

| 层级 | 字号（16:9 投影） | 说明 |
| --- | --- | --- |
| 主标题 | 32-40 pt | 封面用 40-44 |
| 页面标题 | 28-32 pt | 不要小于 24 |
| 正文 / 要点 | 20-24 pt | **小于 18 pt 就等于没写** |
| 图表轴标与图例 | 16-18 pt | 图例比正文更难读，宁可放大 |
| 注释 / 来源 | 12-14 pt | 只用来说明来源，不给评委读 |

常见错误：把论文段落直接粘进 PPT，字号自动变成 12 pt。**宁可拆成三页，也不要缩字号。**

## 二、每页的字数上限

经验值：**正文不超过 60 字**（不含标题）。超过就往备注里放。

判断方法：站在离屏幕 2 米处，**3 秒内能不能抓住这一页在讲什么**。抓不住就是字太多。

一页只讲一个观点。如果你发现一页里有两个要点，先问是不是该拆页。

## 三、配色：主色不超过 3 种

| 角色 | 建议 | 用途 |
| --- | --- | --- |
| 主色 | 深蓝（如 #1A5FB4） | 标题、强调、流程条 |
| 辅色 | 灰（#5C6B7A） | 次要信息、注释 |
| 强调色 | 橙 / 红（#B45309 / #B3261E） | 问题、风险、重点数据 |
| 中性底 | 白 / 极浅灰（#F6F8FA） | 背景、表格底 |

**不要用渐变背景 + 艺术字 + 阴影**。学术答辩要的是清晰，不是炫技。

BIM 项目特有的配色约定：碰撞点用**红色**高亮、调整后用**绿色**、待复核用**橙色**——并且要在图例里写明，否则评委会以为红色是装饰。

## 四、图表选择：什么数据配什么图

| 你要表达 | 用什么 | 不要用 |
| --- | --- | --- |
| 碰撞按专业对分类 | 堆叠柱状图 / 分组柱状图 | 饼图（类别超过 5 个就看不清） |
| 优化前后对比 | 对比柱状图（两根柱） | 折线图（没有时间维度） |
| 严重程度分级占比 | 饼图（3-4 类） | 柱状图（占比用柱状不直观） |
| 进度计划 | 甘特图 | 表格罗列日期 |
| 工程量偏差 | 双柱对比 + 偏差率标注 | 只给一张表 |
| 空间关系 | 三维轴测 / 剖面 | 平面图（看不出高差） |

**每张图必须有标题、单位、图例、数据来源。**缺单位的数字图表，评委一定会问。

## 五、模型与截图：BIM 答辩的特有要求

1. **截图要带界面上下文**：只说"这是碰撞结果"不够，要能看到软件界面或视图名称，证明是你自己导出的。
2. **剖面图要标剖切方向**：一条带箭头的剖切线 + 剖面编号。
3. **对比图必须同视角**：优化前后的截图要用同一角度、同一缩放，否则评委无法判断差异。
4. **模型截图加比例参照**：放一个人形剪影或尺寸标注，否则评委对尺度无感。
5. **不要用网络素材图**冒充自己的成果——一旦被追问细节就崩。

## 六、动画：克制到几乎看不到

- 允许：淡入、擦除、按点击逐条显示要点。
- 禁止：旋转、飞入、弹跳、多物体自定义路径。
- 4D 与漫游动画：**剪辑到 10-30 秒**，只放关键段。放整段 3 分钟视频 = 让评委看视频，不是听你答辩。
- 动画视频**本地嵌入或超链接到本地文件**，不要用在线视频（现场断网即崩）。

## 七、页面骨架：每页的固定元素

建议每页都放：

```
┌─────────────────────────────┬───────────────┐
│ 页面标题（一句话结论）        │  页码 / 章节标 │
├─────────────────────────────┴───────────────┤
│                                             │
│   主内容区：一图 + 不超过 60 字               │
│                                             │
├─────────────────────────────────────────────┤
│ 数据来源 / 说明（小字，可选）                  │
└─────────────────────────────────────────────┘
```

**标题要写成结论，不要写成名词**。

- 弱：「管线综合成果」 → 强：「管线综合后走廊净高由 2.35m 提升至 2.60m」
- 弱：「碰撞检测」 → 强：「整合模型发现 312 处碰撞，已解决 47 处严重碰撞」

标题即结论，评委只看标题也能拿到信息——这是最省力的加分技巧。

## 八、常见排版事故自查

- [ ] 最小字号 ≥ 18 pt
- [ ] 每页正文 ≤ 60 字
- [ ] 每页只有一个核心观点
- [ ] 所有图表有单位与来源
- [ ] 没有网络素材图充当自己成果
- [ ] 同一页内字号层级不超过 4 级
- [ ] 颜色不超过 3 主色
- [ ] 动画只用淡入 / 擦除
- [ ] 视频已导出为本地文件并可播放
- [ ] 标题写成了结论而非名词
