# 答辩倒排时间线

答辩不是"上台前一晚把 PPT 做完"，而是一条倒排的工作链。下面按 **T-7 天到 T-0** 拆解。如果你的时间更紧，按比例压缩，但**不要跳过 T-2 的口头演练和 T-1 的问答演练**——这两步是最省分的。

## T-7 天：定主线

| 任务 | 完成标准 |
| --- | --- |
| 写出一句话主线 | 「本项目用 BIM 解决了 ______ 这个具体问题。」写不出 → 说明还没想清，先别做页 |
| 列出工程重难点 3-5 条 | 每条都要能对应到后面某个 BIM 应用点 |
| 列出 BIM 应用点 | 每个应用点都要能回指到某条重难点；对不上的删掉 |
| 定 PPT 页数 | 按汇报时长定：10 分钟 → 8-9 页；15 分钟 → 11-13 页；20 分钟 → 14-16 页 |

## T-6 天：搭骨架

- 按页面库顺序建好每页，**每页先只写一个观点 + 一个结论式标题**。
- 把用户/项目数据（规模、碰撞数、净高、工期、算量对比）填进对应页；**填不出来的就是待补充，标红**。
- 自检：遮住任意一页，问「删了它主线还成立吗」——成立就移到附录备用页。

## T-5 天：补素材

- 模型截图：总装、分专业、剖切、关键节点，**同一视角成对截图**（优化前 / 优化后）。
- 导动画：漫游与 4D 各剪辑到 10-30 秒，导出为本地 mp4。
- 做图表：碰撞统计、偏差对比、进度对比。
- 建附录备用页：完整碰撞清单、完整明细表、软件设置截图、WBS 全表、规范条文摘录。

## T-4 天：排版与自检

- 按《PPT 页面设计与排版规范》过一遍：字号、字数、配色、动画。
- 导出 PDF 备份（这是最后一道防线）。
- PPT 三份备份：U 盘 / 邮箱 / 网盘。

## T-3 天：出声计时演练（第一次）

- **必须出声 + 掐表**，连练 3 遍，记录总时长与每段时长。
- 目标：正片讲到你设定时长的 **90%**。
- 砍掉超时最严重的段落 20%——通常是项目背景。
- 把念不顺的句子改写成人话。凡是"写出来顺、念出来别扭"的句子，评委立刻能听出是抄的。

## T-2 天：定稿 + 第二次计时演练

- 按演练结果定稿，不再改结构（改结构就要重新计时）。
- 再练 2 遍，目标是**不看稿也能讲完**。
- 检查口头禅（"然后""这个""就是"），录像回看一遍。
- 把高频 5 问的答案写成**小卡片**，答辩当天放手边。

## T-1 天：问答演练

- 找同学当假评委，拿提问预案逐条问，**必须口头回答**，不能在心里想。
- 重点练"不知道"的问题：练熟「承认 + 给一点思路 + 会后整改」三步。
- 练翻附录：评委问细节时，3 秒内翻到对应备用页。
- 准备材料：打印论文 1-2 份、数据速查卡、提问预案卡。
- 提前确认答辩地点、时间、设备（投影比例、翻页笔）。

## T-0 当天

| 时点 | 动作 |
| --- | --- |
| 提前 40 分钟 | 到场地，试放 PPT，确认字体不乱码、动画能播、视频有声 |
| 提前 15 分钟 | 调投影分辨率（16:9 / 4:3 是否匹配）、试翻页笔、手机静音 |
| 上台前 5 分钟 | 深呼吸，扫一眼数据速查卡上的 5 个关键数字 |
| 开场 | 15 秒内说完题目，立刻翻页 |
| 汇报中 | 眼睛看评委，不要盯屏幕；语速比练习时略慢 |
| 提交时 | 把打印的材料递给评委，笔拿出来准备记录 |
| 提问环节 | 每题先"谢谢老师，我从三个方面回答"，答完明确说"回答完毕" |
| 全程 | 记录评委意见（这个动作本身就是加分项） |

## 当天现场检查表

- [ ] PPT 能在答辩电脑上正常打开（已试放）
- [ ] 特殊字体未变形（或已嵌入 / 用 PDF 备份）
- [ ] 4D 与漫游视频本地可播，音量正常
- [ ] 翻页笔可用（备电池）
- [ ] 打印材料：论文、数据速查卡、提问预案卡
- [ ] 手机静音、口袋里有一支笔
- [ ] 知道附录备用页在第几页
- [ ] 五个关键数字能脱口而出
