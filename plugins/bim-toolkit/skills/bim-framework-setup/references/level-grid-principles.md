# 标高轴网设计原则

本文件整理各类 BIM 项目在标高与轴网设计上的共性原则。项目专属数值见 `assets/framework_kb.json`，本文件只讲「为什么这么定」。

## 一、标高的共性原则

### 1. 基准先于数值

任何项目在填标高数值之前，必须先回答三个问题：

1. **±0.000 对应什么？**（首层室内地面 / 设计地面 / 井口 / 广场地面……不同项目类型答案完全不同）
2. **绝对标高与相对标高的关系是什么？**（相对值必须在总图说明中给出换算依据）
3. **室外/地表标高与室内差多少？**（高差同时决定排水、台阶与无障碍设计）

**最常见的错误是跳过第 1 问直接填数**——比如在铀矿巷道里按「层高」思维填标高，会导致中段无法对齐、坡度无法表达。

### 2. 建筑标高与结构标高必须分开

两者相差一个面层厚度（通常 50mm）。混用的典型后果：结构模型与建筑模型在同一标高上「叠住」，或者楼板厚度统计错误。Revit 中应建立两套标高类型（或用「结构标高」参数区分），并在框架说明书中写明面层厚度差。

### 3. 竖向贯通构件是标高体系的校验器

楼梯、电梯井、管道井、风井必须上下层对齐。如果建模时发现竖井错位，问题通常不在竖井本身，而在标高或轴网定义错了。**竖井对齐是标高体系正确性的间接校验手段。**

## 二、轴网的共性原则

### 1. 轴网服务于功能模数，不是反过来

先确定主要使用空间的尺寸，再反推轴网间距：

| 项目类型 | 决定轴网的功能因素 |
| --- | --- |
| 教学楼 | 教室开间×进深（中学标准教室约 8.1m × 7.5m） |
| 双拼别墅 | 户型开间（3.9m / 4.2m）与分户墙对称轴 |
| 地下综合管廊 | 标准节长度（变形缝 25m）与舱室分隔 |
| 铀矿巷道 | **勘探线间距**（25m / 50m），不是柱网 |
| 盾构隧道 | **里程桩号 + 环号**（1.2m / 1.5m），无传统轴网 |
| 基坑支护 | 围护边线 + 支撑轴线 + 立柱桩定位 |
| 英雄纪念碑 | 中心对称轴（视轴方向），无柱网 |

**先画一个「标准柱网」再往里塞功能**是通用性最强的错误，在矿山/隧道类线性工程中后果尤其严重（轴网不对齐勘探线或里程，地质模型与构筑物模型的空间关系全部失效）。

### 2. 线性工程不用建筑轴网

盾构隧道、管廊、巷道这类沿某一方向延伸的工程，定位基准是**里程/桩号/环号**而非直角轴线网格。用建筑轴网思维建线性工程，会导致：

- 里程中途重新起算，两段模型无法拼合；
- 平面曲线（缓和曲线、竖曲线）无法表达；
- 环号与里程对应关系错乱，联络通道定位随之漂移。

### 3. 总平面轴网与建筑轴网共用坐标系

两套轴网可以分开建，但**坐标系必须一致**（项目基点与测量点一致）。链接模型时用「原点到原点」，绝不能用「中心到中心」。

### 4. 影响范围统一为 3D

Revit 中轴网/标高的影响范围有 3D 与 2D 两档。教学与协同项目统一用 3D，否则不同视图里轴网长度不一致，出图时会暴露为低级错误。

## 三、标高轴网的常见错误模式

| 错误 | 表现 | 后果 |
| --- | --- | --- |
| 基准未定就填数 | 标高值与实际场地对不上 | 全部构件高程错误，改基准牵动全模型 |
| 层高思维套线性工程 | 巷道/隧道按楼层建 | 坡度无法表达，中段/环号对不上 |
| 轴网自拟间距 | 不对齐勘探线/功能模数 | 地质模型与构筑物错位；柱子压占功能空间 |
| 竖井不对齐 | 排水横管在楼板内长距离穿行 | 施工无法实现，属功能性错误 |
| 楼层漏标高 | 通高空间、夹层、设备层遗漏 | 楼板统计与面积统计错误 |
| 中途改轴网 | 已建构件跟随错位 | 返工量与已建构件量成正比 |

## 四、实操顺序建议

1. 设置项目单位、项目基点、测量点、正北；
2. 建标高（先建基准标高，再阵列/复制其余）；
3. 建轴网（按方案表逐条绘制，锁定间距）；
4. 调整影响范围为 3D；
5. 建视图样板（至少平面/立面/剖面/3D 四套）；
6. 组织项目浏览器；
7. 规划工作集（单人项目也要做，避免后期拆分）；
8. 框架自检（见 `standards.json` 的 `framework_checklist`）。

以上顺序中，第 1 步与第 8 步最容易被跳过，也最不该跳过。
