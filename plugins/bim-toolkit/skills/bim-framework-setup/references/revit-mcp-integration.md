# Revit MCP 连接器协作指南

本文件说明「BIM 建模框架搭建助手」在检测到 / 未检测到 Revit MCP 连接器时的行为差异，以及自动创建时的安全边界。

## 一、检测方法

按顺序检查，任一命中即判定为「已配置」：

1. **配置文件**：`~/.workbuddy/mcp.json` 存在，且其 `mcpServers` 中含有 Revit 相关条目（如 `revit-mcp`、`revit_mcp`、`revit` 等键名）。
2. **可用工具列表**：当前会话可用工具中出现 Revit 相关工具（通常以 `mcp__revit` 或含 `revit` 字样命名）。
3. **连接器状态**：连接器状态信息中列出 Revit 相关已连接条目。

**判定纪律**：

- 不要仅凭用户提到「Revit」就判定已配置——用户装了 Revit 软件不等于配置了 MCP 连接器。
- 若无法确认，按「未配置」处理，并如实告知用户「未检测到，如需自动创建请先配置连接器」。
- 判定结果要写入方案书第 7 节（`--revit-mcp` 参数），让用户看到本次采用了哪个分支。

## 二、未配置时的行为（默认）

只输出方案与步骤清单：

- 第 1—4 节：标高轴网、专业拆分、LOD 规划、协同计划（应建成什么）；
- 第 6 节：Revit 操作步骤清单（每步含命令路径与校验点）；
- 第 7 节：明确说明「未检测到连接器，以下为手动操作指引」，并给出配置连接器的方法。

**不要在未配置时假装能操作 Revit，也不要替用户「想象」操作结果。**

## 三、已配置时的行为

先问，后动。按 `standards.json` → `revit_mcp.detected` 的流程：

1. **询问**：是否需要直接在 Revit 中创建标高、轴网与基础构件？给出两个选项（自动创建 / 只给方案）。
2. **只读探查**（用户同意自动创建后才做）：
   - 当前打开的项目文件是什么；
   - 已有哪些标高、轴网；
   - 项目基点与测量点设置；
   - 是否已有其他专业模型链接。
3. **参数确认**：把方案中的标高值与轴网间距逐条列出，请用户逐条确认。**用户未确认前不执行写操作。**
4. **逐项创建**：先标高、后轴网、再基础构件（如用户要求）。每步创建后回读核对。
5. **差异报告**：把实际创建内容与方案逐条比对，输出差异说明（含失败项与原因）。

## 四、自动创建的安全边界

以下规则在任何情况下不得违反：

| 规则 | 含义 |
| --- | --- |
| 先读后写 | 任何写操作前必须先读取当前项目状态，确认不会覆盖已有成果 |
| 参数确认制 | 标高值与轴网间距必须逐条取得用户确认，不得自行取值 |
| 可回退 | 操作前提醒用户保存或另存副本；创建后如不符预期可撤销 |
| 不做破坏性操作 | 不删除已有标高、轴网、构件；需修改时先说明影响范围并取得确认 |
| 如实回报 | 成功与否逐条回报；失败项说明原因，不得笼统称「已完成」 |
| 顺序不可跳 | 标高先于轴网，轴网先于构件——跳序会导致对位关系错误 |

## 五、常见失败场景与处理

| 场景 | 处理 |
| --- | --- |
| Revit 未打开项目 | 提示用户先打开或新建项目，不要自行决定打开哪个文件 |
| 项目已有同名标高 | 报告冲突，询问是复用现有标高还是改名新建，不要擅自覆盖 |
| 项目基点与方案不一致 | 先报告基点差异，由用户决定以哪个为准——**基点错位会让全部构件偏移** |
| 单位不符（如海外样板为英尺） | 先把单位改为毫米再创建，否则标高值全部错位 |
| 创建中途失败 | 停止后续步骤，报告已完成项与失败项，不要静默跳过 |
| 轴号被占用 | 报告现有轴号序列，请用户决定编号方案 |

## 六、配置连接器的方法（给用户的指引）

1. 在 WorkBuddy 的「连接器管理」页面右上角进入**自定义连接器**入口；
2. 添加 Revit MCP 服务（需要本机运行对应的 Revit MCP Server，且 Revit 处于打开状态）；
3. 添加后在连接器列表中点击「**信任**」启用该服务；
4. 重新发起本任务即可走「已检测」分支。

注意：即便配置了连接器，标高值与轴网间距仍会先经用户确认——这是本 Skill 的设计约束，不是连接器的限制。
