# LOD 体系与国内标准对照

## 一、两套体系的关系（必须说清的部分）

「LOD 100–500」与「GB/T 51301-2018」是**并行体系，不是等价换算**。

| | LOD 体系 | GB/T 51301-2018 |
| --- | --- | --- |
| 来源 | 美国建筑师协会（AIA）提出，BIMForum 的 LOD Specification 细化 | 中国国家标准 GB/T 51301-2018《建筑信息模型设计交付标准》 |
| 结构 | 单一等级序列 100 / 200 / 300 / 350 / 400 / 500 | 双维：几何表达精度 G1–G4 + 信息深度 N1–N4，配合交付等级 1–4 |
| 法律地位 | 行业惯例（国际项目、院校教学广泛采用），**国内无同名强制规范** | 国家标准（推荐性） |
| 常见误用 | 把 LOD 说成「国标规定」 | 把 G/N 等级与 LOD 一一对应硬套 |

**诚实性要求**：在交付文件、教学材料或评审答辩中，不得把 LOD 100–500 表述为「国家规范要求」。可以表述为：

> 本项目按国际通行的 LOD 分档组织模型深度，并按 GB/T 51301-2018 的几何表达精度（G）与信息深度（N）双维标注对应关系；两套体系属并行口径，正式交付以合同约定的标准为准。

## 二、LOD 各档定义

| 等级 | 名称 | 阶段 | 几何 | 信息 | 典型用途 |
| --- | --- | --- | --- | --- | --- |
| LOD 100 | 概念级 | 策划/方案 | 符号或体量，无实际几何尺寸 | 面积、容积、高度、主要功能 | 方案比选、面积指标测算 |
| LOD 200 | 近似级 | 方案/初设 | 主要构件近似尺寸、形状、位置 | 材质类别、大致规格 | 系统方案确定、性能初判 |
| LOD 300 | 精确级 | 施工图 | 精确尺寸、形状、位置、方向 | 规格型号、可出图可算量 | 施工图设计、工程量统计 |
| LOD 350 | 深化级 | 深化设计 | LOD300 + 连接件、支撑、节点构造 | 连接方式、节点做法、预埋件 | 多专业协同、综合碰撞检测 |
| LOD 400 | 加工级 | 施工/预制 | 加工详图精度，含安装公差 | 加工、装配、安装信息 | 预制加工、施工工序模拟 |
| LOD 500 | 竣工级 | 竣工/运维 | 实测校正后几何 | 运维信息、资产编码、台账 | 竣工交付、运维平台接入 |

### 关键认知

1. **LOD 350 是「协同」真正发生的等级。** LOD300 以下做碰撞检测意义有限——几何还是近似的，撞不撞不可信。
2. **LOD 400 不是「更精细的 LOD300」**，而是「能达到加工精度」——需要产品厂的加工数据支撑，院校项目通常不具备，慎用。
3. **LOD 500 的重点是数据不是几何**——「与实物一致」比「更精细」重要，通常需要点云或实测校正。

## 三、GB/T 51301-2018 的双维体系

该标准不使用单一等级，而是：

- **几何表达精度等级 G1–G4**：从「按类别选用标准化几何图元」（G1）到「满足加工深度要求的精确几何」（G4）；
- **信息深度等级 N1–N4**：从「仅含基础识别信息」（N1）到「含完整深化设计/加工/运维信息」（N4）；
- **交付等级 1–4**：对应方案设计、初步设计、施工图设计、深化设计四个阶段，每个阶段规定了应达到的 G 与 N 组合。

另有 **JGJ/T 448-2018《建筑工程设计信息模型制图标准》**，规定模型出图的图面表达要求，可与 LOD 规划配合使用。

## 四、实践中的对照关系

下表为常用的近似对照（**不是标准条文规定的等价换算**），用于同时满足教学与企业要求：

| 阶段 | GB/T 51301 交付等级 | 几何/信息深度 | 对应 LOD |
| --- | --- | --- | --- |
| 方案设计 | 一级交付 | G1~G2 / N1~N2 | LOD 100~200 |
| 初步设计 | 二级交付 | G2 / N2~N3 | LOD 200 |
| 施工图设计 | 三级交付 | G3 / N3 | LOD 300 |
| 深化设计 | 四级交付 | G3~G4 / N3~N4 | LOD 350~400 |
| 竣工/运维 | （运维阶段交付） | N4（实测校正） | LOD 500 |

## 五、规划 LOD 时的三个动作

1. **明确「到哪一档为止」**：规划表应同时写明各阶段「做到什么」与「不做什么」。例如 LOD300 阶段明确「不做支吊架深化、不做加工级节点」，否则范围会无限膨胀。
2. **与交付物对应**：每一档 LOD 都要落到具体交付物上（图纸、明细表、报告），否则 LOD 只是口号。
3. **与碰撞检测节点对应**：LOD350 才适合做综合碰撞检测；在 LOD200 阶段只适合做空间关系初判。把这个对应关系写进协同计划，避免「模型还不精确就跑碰撞」。

## 六、常见误区

| 误区 | 事实 |
| --- | --- |
| 「LOD 是国标」 | LOD 体系源自美国 AIA/BIMForum；国内对应标准是 GB/T 51301-2018 的 G/N 双维体系 |
| 「LOD 越高越好」 | LOD 高意味着工作量大、维护成本高；规划目标是「够用且可控」 |
| 「LOD350 和 LOD300 差不多」 | LOD350 才包含连接件与节点构造，协同与碰撞检测应从这一档开始 |
| 「教学项目直接上 LOD400」 | LOD400 需要加工数据支撑，教学项目通常到 LOD300 全专业完整即达标 |
| 「LOD500 是终极精细度」 | LOD500 的重点是「与实物一致 + 运维数据」，不是几何更精细 |
