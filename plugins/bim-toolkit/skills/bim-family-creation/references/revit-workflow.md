# Revit 建族工作流（revit-workflow）

对照 `family_standards.json` 的 9 步标准流程，这里展开每一步的操作细节与判断依据。

---

## 底层逻辑

```
参照平面  →  尺寸标注  →  参数  →  几何
（骨架）     （度量）      （驱动）   （外衣）
```

**顺序不可颠倒。** 所有「改了参数几何乱跳」的问题，根因都是几何没有约束到参照平面，而不是参数本身有问题。

---

## 第 1 步 · 选定族样板与类别

Revit 的族样板（`.rft`）决定了四件事，**且选定后基本无法更改**：

| 样板决定的 | 后果 |
| --- | --- |
| 族类别 | 决定明细表可提字段、视图控制规则、标记类型 |
| 宿主关系 | 基于墙/基于面/独立，决定能放在哪、随谁移动 |
| 剪切能力 | 只有门窗等特定类别能剪切墙体，其他类别无此能力 |
| 连接件 | 只有 MEP 样板带连接件，决定能否连入管线系统 |

**判断顺序**（回答完这四个问题，样板就唯一确定了）：

1. 归哪个类别？
2. 是否基于宿主？宿主是谁？
3. 平面/剖面中是否需要剪切宿主？
4. 需要哪些内置参数（如门自带宽度/高度/防火等级）？

**关键警告**：不要为了省事从「公制常规模型」开始建，之后再改类别。类别行为、剪切能力、连接件、分析模型**不会随类别更改而完整转换**。这是个不可逆的选择。

另有一个容易忽略的后果：**常规模型类别统计不到长度、体积、宽度，只能统计个数**。如果你的族需要提工程量，就必须用对应类别的样板。

---

## 第 2 步 · 布置并命名参照平面

- 参照平面可以在任何非三维视图中创建
- 参照平面本身会投射到垂直视图中，**不需要重复创建**
- 布置原则：凡是尺寸可能变化的边界，都要有参照平面
- 命名：点击参照平面的标签，或在属性面板中重命名

**命名规范**：用语义化名称，如 `宽度左` / `宽度右` / `洞口上` / `洞口下` / `中线`。
不要留 `参照平面 1` 这种默认名——一个族有 20 个参照平面时，默认名会让你无法排查问题。

**对称/居中关系**必须用参照平面实现，而不是靠几何对称。
原因：几何会被参数推动，参照平面才是稳定的基准。

---

## 第 3 步 · 标注尺寸并赋予参数

用尺寸标注量出参照平面间距，选中尺寸后通过「标签」下拉创建参数。

**这一步是全流程最容易造成不可逆错误的地方**，因为：

> 参数的类型/实例属性**创建后不可更改**。选错只能删除参数重建，并重新关联所有几何。

创建参数时要确认的六项：

| 项 | 说明 |
| --- | --- |
| 参数名称 | 语义化、全族统一（见 naming-and-testing.md） |
| 参数类型 | 类型 / 实例 —— 见 parameter-design.md 的决策规则 |
| 参数分组方式 | 尺寸标注 / 标识数据 / 材质和装饰 / 结构 / 机械 …… |
| 数据/参数类型 | 长度 / 角度 / 整数 / 数值 / 文本 / 是/否 / 材质 |
| 单位 | 长度类默认按项目单位（中国习惯为 mm） |
| 公式（可选） | 仅在有确定数学关系时使用，不要滥用 |

---

## 第 4 步 · 首次弯曲测试（此时还没有几何）

在「族类型」对话框中修改参数值 → 应用 → 观察参照平面是否按预期移动。

**这是最省力的排错时机**。此时族里只有参照平面，任何一个参数不能驱动参照平面，问题一眼可见。
等到几何建完再测，问题会被几何掩盖，排查成本高一个数量级。

习惯做法是**逐个参数改，不要一次全改**——一次全改出问题时无法定位到具体参数。

---

## 第 5 步 · 创建几何并锁定到参照平面

- 在参照平面上绘制轮廓（拉伸 / 放样 / 旋转 / 融合 / 空心）
- 进入草图模式后，用「对齐」工具把轮廓线对齐到参照平面并锁定
- **每条轮廓线都要锁定**

**铁律**：只把几何锁到参照平面或参照线，**永远不要把几何边锁到另一个几何边**。

违反这条会出现 Revit 的经典警告：

> 「族内几何图形之间的约束在参数修改时可能不可预测。为使族可靠，请将几何图形约束到标高、参照平面或参照线。」

**遇到这个警告的处理**：
1. 用「管理」选项卡 →「按 ID 选择」定位到具体约束
2. 选中后右键「显示相关」，看清是哪部分几何
3. 把约束重新定义到参照平面
4. 如果定位困难，可用警告对话框的「删除约束」批量清除，然后重新按正确方式约束

修复的核心是**删除冗余锁定**，而不是再加新的约束。

---

## 第 6 步 · 材质、子类别与可见性

**材质**：创建材质参数 → 选中几何 → 在属性面板把「材质」关联到参数。
不要直接给几何赋一个固定材质——那样参数就失去意义。

**子类别**：为需要独立控制线型/填充的几何建立子类别。
不要只依赖类别本身来做图形控制，粒度不够。

**可见性**：
- 三维几何默认可见
- **二维符号线必须显式指定可见性**（在属性面板的「可见性/图形替换」中设置所属视图与详细程度）
- 不设置会出现：平面视图一片空白、标记读不到、幽灵图元

**详细程度**：为粗略/中等/精细三种程度规划不同表达。
小构件在粗略程度下应简化，避免图纸糊成一团。

---

## 第 7 步 · 嵌套族与阵列

**嵌套族**（把构件拆成独立的小族再组合，是控制复杂度的核心手法）：

1. 子族自身的参照点/坐标原点必须与几何中心一致——否则对齐时没有可靠基准
2. 主族中放置子族实例后，**必须用「对齐」工具（AL）把子族的关键边或中心线锁到主族的参照平面**
3. 选中子族实例 → 属性面板中点击参数右侧的关联按钮 → 与主族参数关联
4. 需要暴露给主族控制的子族参数，在子族中应创建为**共享参数**

**阵列**：

1. 创建阵列时必须勾选「成组并关联」
2. 阵列完成后选中阵列组，在选项栏把「数量」标签关联到一个整数参数
3. **锁定第一个和最后一个构件**到边界参照平面（或用公式控制首末位置）

不锁首末 + 不关联数量 = 改尺寸时阵列不跟随，出现半截构件或间隔不均。

---

## 第 8 步 · 建立族类型

在「族类型」对话框中为每个规格新建类型并赋值。

- 类型数量少（≤10）：直接在主族中建
- 类型数量多（几十上百）：使用**类型目录（Type Catalog）**——一个 `.txt` 文件与族同名同目录，Revit 载入时可选类型

类型命名建议：`{构件简称}-{关键规格}`，如 `KL-300x700`、`SG-φ6200`。

---

## 第 9 步 · 测试与发布

按 `family_standards.json` 的 `testing_methods` 逐项测试，详见 naming-and-testing.md。

**发布前必做**：
1. 「清除未使用项」——删掉建模过程中产生的废弃几何、材质、参数
2. 检查文件体积与载入速度
3. 确认命名符合规范
4. 记录族参数说明（供团队查阅）

---

## 版本注意事项

- Revit 各版本的菜单结构有差异，找不到命令时用顶部「搜索命令」输入英文关键词（如 `Sweep`、`Reference Plane`）
- 结构连接等专业功能在新版本有变化（Revit 2020 之后钢连接改用 Steel Connections 扩展），涉及钢结构细节时应确认目标版本
- 族文件的向下兼容性有限：高版本保存的族在低版本中无法打开，团队协作前应统一版本
